# ai-certification-roadmap
AI 자격증·무료 교육 비교와 개인 학습 진행률을 관리하는 로컬 웹 도구 / AI certification roadmap and learning tracker

## 기능
- **비교하기**: 자격증 10개 · 교육 9개 기본 수록. 종류·난이도·기관·무료 여부·검색어로 필터
- **내 로드맵**: 항목별 상태(계획/진행 중/완료/보류), 진행률, 목표일(D-day), 메모
- **요약**: 로드맵 항목 수, 진행 중·완료 수, 평균 진행률(보류 제외)
- **항목 추가**: 사내 교육 등 직접 추가 (링크는 http/https만 허용)
- **백업**: JSON 내보내기·가져오기
- 다크 모드, 모바일 화면 지원

## 실행
`index.html`을 브라우저로 열면 됩니다. 설치·서버·외부 요청이 없습니다.

## 데이터에 대해
- 기본 항목은 `data.js`에 있습니다. 시험 코드·응시료·개편 일정은 자주 바뀌므로 **일부러 넣지 않았습니다**.
  응시 전에는 각 카드의 **공식 링크**에서 최신 정보를 확인하세요.
- 내 계획·메모는 이 브라우저의 `localStorage`에만 저장됩니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `data.js` | 기본 자격증·교육 목록 |
| `roadmap.js` | 필터·진행률·요약·백업 로직(UI 없음) |
| `roadmap.test.js` | 단위 테스트 — `node --test` |

## 검증
- 단위 테스트 8개 통과 (데이터 무결성 포함, Node 22)
- Chromium 자동 점검: 필터·검색·로드맵 추가·완료 처리·D-day·새로고침 후 유지·잘못된 링크 거부·백업 복원·모바일 폭·콘솔 오류 없음
